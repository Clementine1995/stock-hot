# 开盘啦数据源调研结论（留档）

> 日期：2026-11-14
> 性质：阶段 A 只读调研结论，作为后续开发的依据。本文档记录的是**已实测验证**的事实与**待确认**的缺口，不编造。

## 一、核心结论（一句话）

开盘啦的「板块强度」等核心行情数据可通过**老版本匿名接口（`apiv=w42`）直接获取，无需 token、无需抓包、无需真机/模拟器**；「市场情绪温度计 0–100」未在匿名接口暴露，改为**用公开原料自算**（已与用户确认走方案 A）。

## 二、数据源选型

| 候选 | 结论 |
|---|---|
| 抓包开盘啦 APP（mitmproxy） | **不需要**。老版本匿名接口可直连，免 token |
| AKShare 公开数据 | 保留为备选/补充源，不当前主线 |
| Tushare kpl_list | 需 token+积分、次日入库，不采用 |
| 通达信（已连接） | 无开盘啦私有指标，仅作补充 |

## 三、已实测验证的匿名接口（真实返回，2026-11-13 数据）

访问域名：`apphis.longhuvip.com`（历史）与 `apphwhq.longhuvip.com`（当日）。
请求公共参数：随机 `DeviceID`（uuid4）、`apiv=w42`、`VerSion=5.21.0.2`，**无 UserID/Token 字段**。

### ① 全板块强度排名 `RealRankingInfo`（`c=ZhiShuRanking`）
- 参数要点：`Order=1&st=30&Index=0&Type=1&ZSType=7&Date=YYYY-MM-DD`
- 返回：板块代码、名称、**强度**、涨跌幅、量比、成交额、主力净额等，按强度降序，分页可拿全 267 个板块。
- 实测样例：AI应用 4637 · 芯片 4466 · 文化传媒 3712 · 银行 1143 · 游戏 868 · 机器人概念 565 … 农业 -16 · 中特估 -22 · 破净股概念 -123

### ② 市场情绪 `MoodNumCount`（`c=MarketMood`）
- 返回：上涨 765 / 下跌 4748 / 涨停 37 / 跌停 33 / 涨跌比 -14.33 等家数类字段。

### ③ 单板块强度历史 `GetPlate_Info_QJ`（`c=ZhiShuRanking`）
- 参数要点：`PlateID=<板块代码>&Date=YYYY-MM-DD`
- 返回：`List` 数组，字段映射：`List[0]=? · List[1]=强度 · List[2]=成交额 · List[3]=主力净额 · List[4]=涨跌幅% · List[5]=涨停数 · List[6]=涨停封单 · List[7]=?`
- 实测样例（机器人概念 801159）：强度 565 · 成交额≈4479 亿 · 主力净额≈-33 亿 · 涨停 5

### ④ 全市场情绪历史 `HisZhangFuDetail`（`c=HisHomeDingPan`）— 2026-11-17 补充
- 参数要点：`a=HisZhangFuDetail&c=HisHomeDingPan&Day=YYYY-MM-DD`（历史域 apphis，匿名），注意用 `Day` 而非 `Date`。
- 返回 `info` 字典，**支持历史回查**，口径与 `MoodNumCount` 一致：
  - `SZJS`=上涨家数 · `XDJS`=下跌家数 · `SJZT`=实际涨停 · `SJDT`=实际跌停
  - `ZT`/`DT`=含 ST 的涨停/跌停总数 · `STZT`/`STDT`=ST 涨停/跌停数
  - `sign`=市场人气高低（如「市场人气低迷 / 市场人气高涨」）
  - 另有涨跌幅分布（`-10`~`10` 各档家数，字符串键）
- 实测样例：2026-11-13 → 涨 765/跌 4748/实涨 37/实跌 33（与 MoodNumCount 一致）；2026-11-10 → 涨 4273/跌 1149/涨停 95/跌停 0，sign=市场人气高涨。
- 意义：**解开了「情绪温度历史不可回查」的死结**——温度公式的 4 个原料（涨跌家数+涨停跌停）全部可历史回查，历史温度与当日温度同口径、可同曲线。

## 四、「负强度」疑点已解

开盘啦强度值**本身有正有负**：正=走强（样例图红色段）、负=走弱（样例图绿色段）。直接对应样例「题材强度轮动」面板的上下两段。

## 五、情绪温度：自算方案（方案 A，已确认）

匿名接口只暴露涨跌家数/涨停跌停家数/涨跌比等原料，**不直接暴露温度计 0–100**。
采用自算：用涨停数、跌停数、连板率、炸板率、涨跌家数、涨跌比、赚钱效应等原料，加权映射到 0–100 温度值。
- 已落地 v1 公式（`src/indicators/mood.py`）：广度项=(涨−跌)/(涨+跌)×30 + 强度项=clamp((涨停−跌停)×0.2,±30)，温度=clamp(50+广度+强度, 0, 100)。系数经 2026-11-17 用 30 个交易日回测标定（初版 ×50/×0.5 导致 8/30 天贴顶贴底，标定后 0 天、中位数约 51）。
- 本质与开盘啦温度计同源（它也是综合这些维度），但公式由本项目自主定义、可解释、可回查。
- **2026-11-17 更新**：原料（涨跌家数+涨停跌停）已确认可经 `HisZhangFuDetail` 历史回查，历史温度曲线可完整回补、口径一致。

## 六、待确认 / 缺口

1. **市场情绪温度计 0–100 真值**：匿名接口未暴露，已决定自算（不再抓包）。
2. **情绪温度自算公式**：待设计，需用户确认。
3. **字段映射中的未知项**：`GetPlate_Info_QJ` 的 `List[0]`、`List[7]` 等字段语义待实测确认。
4. **接口稳定性**：`apiv=w42` 为老版本接口，存在被开盘啦下线/收紧的风险，需做降级预案（如 AKShare 兜底）。
